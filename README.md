# Yoruakari.nvim

A dark Neovim colorscheme inspired by the night sky illuminated by colorful lights.

The UI stays dark and neutral while syntax and semantic elements provide muted blue, cyan, green, yellow, red, purple, orange, and pink accents.

## Requirements

- Neovim 0.9+

## Installation

### vim.pack (Neovim 0.12+)

```lua
vim.pack.add({
  "https://github.com/gilpra/yoruakari.nvim",
})

vim.cmd.colorscheme("yoruakari")
```
